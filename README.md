# Yoyo Makeover — เว็บไซต์ร้านสักคิ้วโหงวเฮ้ง เพชรเกษม 69

เว็บไซต์ 5 หน้า สร้างด้วย **Next.js 15 (App Router) + TypeScript**

| หน้า | Path | เมนูย่อย |
|---|---|---|
| หน้าแรก | `/` | |
| เกี่ยวกับเรา | `/about` | |
| บริการของเรา | `/services` | สักคิ้วโหงวเฮ้ง, คิ้ว 12 นักษัตร, แก้คิ้ว, สักตาหวาน, สักปากชมพู, ต่อขนตา |
| ผลงานของเรา | `/portfolio` | คิ้วโหงวเฮ้ง, แก้คิ้ว, ตาหวาน, ปากชมพู, ขนตา, รีวิว |
| ติดต่อเรา | `/contact` | ฟอร์มจองคิว (ส่งต่อไป LINE) + แผนที่ |

## เริ่มพัฒนา

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## แก้ไขเนื้อหา

เนื้อหาทั้งหมดอยู่ที่ไฟล์เดียว: `lib/site.ts`

- `CONTACT` — เบอร์โทร, LINE, ที่อยู่, เวลาทำการ
- `IMG` — รูปภาพ (ตอนนี้ใช้รูปจาก Unsplash) เปลี่ยนเป็นรูปจริงได้โดยวางไฟล์ใน `public/images/` แล้วใส่ `"/images/xxx.jpg"`
- `SERVICES`, `PORTFOLIO`, `REVIEWS`, `FAQ` — ข้อมูลบริการ ผลงาน รีวิว คำถาม

สีแบรนด์ (CI) อยู่ที่ตัวแปร `:root` ด้านบนของ `app/globals.css`
